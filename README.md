# Plan

[下载最新版 APK](https://github.com/2155957130/Plan-app-android/releases/download/v1.5.0/Plan.apk)

## 待办

- 创建待办，设置截止日期、时间、标签、备注和提醒。
- 完成后归入已完成列表，也可撤销完成状态。

## 打卡

- 创建习惯，按每天、工作日、自选星期、间隔天数、每月指定日或每年指定月日安排打卡。
- 查看连续打卡记录和狗爪脚印进度。

## 日历

- 按日期查看待办与习惯组成的时间线，并按时间顺序排列。

## 我的

- 查看待办完成率与习惯坚持记录。
- 使用今日待办和习惯打卡桌面小组件。

## 设置

- 管理通知与准时提醒。
- 导出本地 JSON 备份，并导入恢复记录。
- 离线使用，无需注册账号。
